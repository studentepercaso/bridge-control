# Support

Bridge Control is community-maintained public preview software.

- Read the [English README](README.md) or [Italian README](README.it.md).
- Search existing [issues](https://github.com/studentepercaso/bridge-control/issues).
- Use synthetic information in public reports.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Support is best-effort. For problems in the external runtime, use the [Obsidian Bridge issue tracker](https://github.com/studentepercaso/obsidian-bridge/issues).

## Italiano

Bridge Control è un'anteprima pubblica mantenuta dalla community.

- Consulta il [README italiano](README.it.md).
- Cerca tra le [segnalazioni esistenti](https://github.com/studentepercaso/bridge-control/issues).
- Nelle segnalazioni pubbliche usa soltanto informazioni sintetiche.
- Segnala le vulnerabilità in privato seguendo [SECURITY.md](SECURITY.md).

Il supporto è fornito senza garanzia. Per problemi nel runtime esterno usa le [segnalazioni di Obsidian Bridge](https://github.com/studentepercaso/obsidian-bridge/issues).
